# 3D1 - 环形结构光点云重建系统

本项目是一套基于**鱼眼相机 + 环形结构光 + 精密二维平移台**的高精度三维测量与点云重建系统。

## 文档与知识库导航

* [**算法知识库 (知识库.md)**](知识库.md)：收录项目中验证成熟的工程算法、数学方案、使用条件与应用场景。
  * **词条 01**：基于多视角消影线（灭线）的自适应度量整平与光平面姿态反解算法（解决透视畸变、梯形/歪四边形无损拉平与光平面姿态反解）。
* [**核心数学公式速查手册 (知识库_数学公式.md)**](知识库_数学公式.md)：收录光强加权图论主干提取与闭环去毛刺的核心数学公式定义、通俗功能、结果与参数含义。
