## 用户需求

将 `image_processing` 中第 503 行 `points.append(np.argwhere(pruned == 255))` 的骨架像素取点方式，替换为**灰度质心亚像素法**提取光条中心，使 points 中的坐标从整数骨架点升级为亚像素精度的光条中心点。

## 核心功能

对 `_prune_and_simplify(skeleton)` 得到的 pruned 骨架图上每个灰度值为 255 的像素，依次执行：

1. **拟合直线求法线**：找到该像素沿骨架方向的前 2 个、后 2 个相邻像素，与当前点共 5 点拟合成一条直线，求出该直线的法线方向。
2. **划定采样大范围**：以该像素为中心，沿法线方向前后各取 15 个像素，作为灰度采样范围（共 31 个采样点）。
3. **差分定位光条两边界**：从法线两端分别向中心点方向做差分（跨度 k=4，公式 `score = |Σ(gray[i] − gray[i+j])|`，j=1..4），在两端各找到差分求和绝对值最大的像素位置，作为光条的两个边界。
4. **灰度质心求亚像素坐标**：在左右两边界之间的法线像素上，用灰度值做加权质心，得到亚像素坐标。
5. **存入 points**：将每个亚像素点坐标（[y, x] float）存入 points，替代原来的 `np.argwhere(pruned == 255)`。

## 约束与兼容

- 采样灰度使用高斯模糊后的 `blur`（`blur = GaussianBlur(img,(5,5),0)`）。
- points 每项保持 [y, x] 格式；下游 `重建.py` 已用 `np.asarray(points, np.float64)[:, ::-1]` 处理，天然支持 float 亚像素坐标，无需改动下游。

## 技术方案

### 实现策略

复用现有 `_ordered_paths` 获取 pruned 的有序骨架点列，对每个点用 PCA 求主方向（复用 `_fit_direction` 思路）得到法线，沿法线在 `blur` 上采样灰度，用差分定位光条两边界，在边界间做灰度质心得到亚像素坐标。

### 关键实现细节

**1. 获取前后相邻像素**

- `_ordered_paths(pruned)` 返回 `(seg, closed)`，seg 是 `(P,2)` 的 `(x,y)` 有序点列，pruned 为闭合大环时 `closed=True`。
- 对闭合环用环形索引取窗口 `seg[np.arange(i-2, i+3) % p]`（前后各 2 点 + 当前点，共 5 点）。
- 开放段两端凑不满 2 个点时跳过（`i < 2 or i > p-3`），段长 `p < 5` 整体跳过。

**2. PCA 求法线方向**

- 对 5 点窗口中心化后计算 `sxx, syy, sxy`，主方向角 `θ = 0.5·arctan2(2·sxy, sxx−syy)`。
- 方向向量 `d = (cosθ, sinθ)`，法线单位向量 `n = (−sinθ, cosθ)`。

**3. 沿法线采样 blur 灰度**

- 采样位置 `pos(t) = c + t·n`，`t ∈ [−15, +15]`（中心索引 15）。
- 用最近邻取整并 clamp 到 `[0, w−1]`、`[0, h−1]`，读取 `blur[y, x]` 灰度。

**4. 差分找两边界（k=4，先差分求和再取绝对值）**

- 左半轴（`t ∈ [−15, −4]`）：向中心方向 = t 增大，`score_left(t) = |Σ_{j=1..4}(g(t) − g(t+j))|`，取最大处为左边界 `t_left`。
- 右半轴（`t ∈ [+4, +15]`）：向中心方向 = t 减小，`score_right(t) = |Σ_{j=1..4}(g(t) − g(t−j))|`，取最大处为右边界 `t_right`。

**5. 边界间灰度质心**

- `t_center = Σ_{t=t_left}^{t_right}(g(t)·t) / Σ_{t=t_left}^{t_right}(g(t))`。
- 亚像素坐标 `(x, y) = (c_x + t_center·n_x, c_y + t_center·n_y)`，按 `[y, x]` 存入结果。

**6. 异常与边界处理**

- 采样越界：clamp 到图像边界。
- 无效点跳过条件：`Σg == 0`、`t_right ≤ t_left`（边界顺序异常）、开放段两端不足点。
- 无有效点时返回 `(0,2)` 空数组，保证 points 与 files 一一对应，下游 `重建.py` 已有空点集判断。

### 性能评估

每图约 3500 个前景点，每点 31 次采样 + 两端差分 + 质心，纯 Python 循环单图预计几十毫秒，对现有批处理无性能压力；无需引入 numba/向量化，保持代码可读与改动最小化。
