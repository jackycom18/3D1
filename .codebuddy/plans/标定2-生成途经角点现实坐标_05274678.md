## 产品概述

在现有「标定2」流程中，为每条结构光光线上的途经角点（标志点）同步生成对应的现实坐标（单位 mm），实现像素坐标与现实坐标的一一配对，并保存到 `光线角点.npz`。

## 核心功能

- 在 `标定2.py` 脚本头部新增 8 个锚点的现实坐标常量 `REAL_ANCHORS`，以占位值 `(0.0, 0.0)` 预置，由用户后续自行填写实际数值。
- 新增锯齿波递推函数：以每组起点锚点的现实坐标为基准，对沿途每个途经角点逐点累加生成现实坐标。
- 递推规则：x 方向每次 +0.5；y 方向在 +0.5 与 -0.5 之间交替，即点序为 `(x0,y0) → (x0+0.5,y0+0.5) → (x0+1.0,y0) → (x0+1.5,y0+0.5) …`。
- 起点对齐采用「方案 A」：起点锚点即第一个标志点，其现实坐标等于用户填写的锚点坐标；第一个途经角点对应第 1 步递推，后续依次类推。
- 保存时在 `光线角点.npz` 中新增两组键：`group{i}_real`（每组途经角点对应的现实坐标）与 `anchors_real`（8 个锚点的现实坐标）。

## 实现方案

在现有 `main()` 采角点流程中，为每组途经角点生成与之等长的现实坐标序列，并随像素坐标一起写入 npz。改动最小化，仅涉及脚本头部常量、新增一个纯函数、以及 `main()` 循环与保存段的小幅扩展。

### 核心实现要点

1. **新增常量 `REAL_ANCHORS`**：定义为 8 行 2 列的元组/列表，元素全部为 `(0.0, 0.0)` 占位，行注释标注「锚点 1~8 现实坐标，按 1→2/3→4/5→6/7→8 分组，待用户填写」。索引与像素锚点一一对应：第 i 组（i=0,2,4,6）起点为 `REAL_ANCHORS[i]`，终点为 `REAL_ANCHORS[i+1]`。

2. **新增函数 `_gen_real_coords(x0, y0, count)`**：

- 输入：起点现实坐标 `x0, y0`，途经角点数量 `count`。
- 输出：`(count, 2)` float64 数组，第 k 个角点（k 从 0 起）对应第 k+1 步递推：
    - `x = x0 + 0.5 * (k + 1)`
    - `y = y0 + 0.5 * ((k + 1) % 2)`（y 在 +0.5 与 0 间交替，等效于 ±0.5 交替）
- 使用 `np.arange` 向量化生成，避免逐点循环。

3. **修改 `main()` 循环**（184~199 行）：

- 新增列表 `reals = []`，与 `groups` 同步收集。
- 在 `groups.append(_collect_corners(path, corners))` 之后，取 `x0, y0 = REAL_ANCHORS[i]`，追加 `reals.append(_gen_real_coords(x0, y0, len(groups[-1])))`。
- 两个 `continue` 跳过分支（未吸附/不连通）需同步 `reals.append(np.empty((0, 2), np.float64))`，保证 `groups` 与 `reals` 长度一致。

4. **修改保存段**（201~203 行）：

- `save` 中新增 `anchors_real = np.asarray(REAL_ANCHORS, np.float64)`。
- 循环写入 `save[f"group{i}_real"] = reals[i]`，与 `group{i}` 成对保存。

### 边界与一致性

- 某组角点为空（未吸附或不连通）时，对应 `group{i}_real` 也写入空数组，保证读取端按组配对不越界。
- 递推仅依赖起点锚点坐标与角点序号，与像素坐标具体数值无关，逻辑稳定可复现。
